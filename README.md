# AI Chatbot 🚀

An interactive, secure, and intelligent AI-powered chatbot web application built using Python and Flask.

## Features ✨
- **Real-time Chat:** Instant responses from a conversational AI model.
- **Robust Validation:** Secure backend request handling to prevent crashes from empty or invalid payloads.
- **Persistent Logs:** Automated secure logging of user conversations into a SQLite database.
- **Clean UI:** Responsive frontend with seamless user experience.

## Tech Stack 🛠️
- **Backend:** Python, Flask
- **Database:** SQLite
- **Frontend:** HTML, CSS, JavaScript
